# Race - Delivery App

> Food, pharmacy, groceries and artisans delivered in 30 minutes. Interactive customer, rider and operations flows.

## Features
- Customer ordering across food, pharmacy, groceries and artisan services
- Rider app flow: accept, pick up, deliver
- Operations dashboard for dispatch and order tracking
- 30-minute delivery model

## Tech
HTML, CSS, JavaScript

## Run

Single self-contained build. Open `index.html` in any browser, or deploy the folder as-is to Netlify, Vercel or GitHub Pages.
